Hints that explain themselves

Hinweise, die sich erklären

Each hint says why it appears, which data is behind it and where to click to fix it. Thresholds are set per rule, and a hint can be snoozed until a date.

Jeder Hinweis sagt, warum er erscheint, welche Daten dahinterstehen und wohin du klickst, um ihn zu erledigen. Schwellen stellst du je Regel ein, und ein Hinweis lässt sich bis zu einem Datum zurückstellen.

What a morning looks like

Wie ein Morgen aussieht

A background run fetches every service at start and then every few minutes. Rules read the same data and write hints. Pages show that stored state, so a board opens at once, even when a service is slow.

Ein Hintergrundlauf holt beim Start und danach alle paar Minuten jeden Dienst ab. Regeln lesen dieselben Daten und schreiben Hinweise. Seiten zeigen diesen gespeicherten Stand, deshalb öffnet ein Board sofort, auch wenn ein Dienst langsam ist.

  • Red: act today, e.g. an invoice 12 days overdue
  • Yellow: plan it, e.g. 14.5 unbilled hours at one customer
  • Blue: good to know, e.g. a certificate that renews in 9 days
  • Every rule has its own thresholds and can be switched off
  • Rot: heute handeln, z. B. eine Rechnung, die 12 Tage überfällig ist
  • Gelb: einplanen, z. B. 14,5 nicht abgerechnete Stunden bei einem Kunden
  • Blau: gut zu wissen, z. B. ein Zertifikat, das in 9 Tagen erneuert wird
  • Jede Regel hat eigene Schwellen und lässt sich abschalten

Install

Installation

  1. Create a folder with data and secrets, and a master key. Keep the key safe, but not next to your backups: without it the database cannot be opened. Back up data/andon.db.salt with the database; it is not secret, but needed too.
  2. Download docker-compose.example.yml as docker-compose.yml and set BASE_URL.
  3. Start it, then open /setup and enter the code from the log.
  1. Einen Ordner mit data und secrets und einen Hauptschlüssel anlegen. Den Schlüssel sicher aufbewahren, aber nicht neben den Backups: Ohne ihn lässt sich die Datenbank nicht öffnen. data/andon.db.salt mit der Datenbank sichern; nicht geheim, aber ebenso nötig.
  2. docker-compose.example.yml als docker-compose.yml herunterladen und BASE_URL setzen.
  3. Starten, dann /setup öffnen und den Code aus dem Log eingeben.
mkdir -p andon/{data,secrets} && cd andon openssl rand -base64 32 > secrets/master_key curl -Lo docker-compose.yml https://raw.githubusercontent.com/shrippen/andon/main/docker-compose.example.yml docker compose up -d docker compose logs andon | grep "SETUP CODE"

Backups run on a schedule into data/backups. docker compose exec -u 10001 andon andon backup /data/backups writes one now: database, icons and themes in one archive.

Backups laufen nach Zeitplan nach data/backups. docker compose exec -u 10001 andon andon backup /data/backups schreibt sofort eins: Datenbank, Icons und Themes in einem Archiv.

Questions

Fragen

Does it change anything in my services?Ändert es etwas in meinen Diensten?

Almost never. It reads. The exceptions are actions you start yourself: a Kimai timer, a draft invoice in Invoice Ninja, marking billed time as exported.

Fast nie. Es liest. Ausnahmen sind Aktionen, die du selbst auslöst: ein Kimai-Timer, ein Rechnungsentwurf in Invoice Ninja, abgerechnete Zeit als exportiert markieren.

Do I need Kimai or Invoice Ninja?Brauche ich Kimai oder Invoice Ninja?

No. Without them it is a start page for your homelab. Each service is optional, and the gallery shows demo previews for the ones you do not have.

Nein. Ohne sie ist es eine Startseite für dein Homelab. Jeder Dienst ist optional, und die Galerie zeigt Demo-Vorschauen für die, die du nicht hast.

What about the AI summary?Was ist mit der KI-Zusammenfassung?

It is off unless you add an Anthropic API key. It only sends hint counts, no names, amounts or tokens.

Sie ist aus, bis du einen Anthropic-API-Schlüssel hinterlegst. Sie sendet nur die Anzahl der Hinweise, keine Namen, Beträge oder Tokens.

How many users does it handle?Wie viele Benutzer schafft es?

It is built for one to ten people on one instance, with SQLite. A Raspberry Pi is enough.

Es ist für ein bis zehn Personen auf einer Instanz gebaut, mit SQLite. Ein Raspberry Pi reicht.
